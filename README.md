# How Many Tabs Do You Have Open? — 47

My entry for the make.fun competition "How Many Tabs Do You Have Open?": a program that writes a single number to `/output/entry.txt`. I chose **47** — far above the handful of tabs most people keep open, the count of a genuine tab hoarder, yet still a number a real person could honestly have open right now. It's odd and specific, not a round guess like 50 or 100: 47 reads like a count someone actually looked at and reported, from a browser where "just one more" article, doc and video never got closed.

## Run it

```sh
python3 main.py
```

This writes exactly `47` (no trailing newline) to `/output/entry.txt`.
